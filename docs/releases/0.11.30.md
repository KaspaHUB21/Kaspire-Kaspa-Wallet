# Kaspire Android 0.11.30 (Build 98) + Extension 0.4.7.1

## HUB21 gold and silver

- New optional HUB21 theme in the app and extension: the same locally packaged
  relief and brushed-metal textures, metallic panels and gold/silver branding.
- Reading surfaces protect labels, instructions, amounts and security notes
  from the detailed background. Midnight remains the default.
- Existing signing, seed generation, authorization and transaction validation
  are unchanged. No remote code or remote theme assets were introduced.

## Asset lists and extension controls

- KCC20, KRC721 collections and KNS join KRC20 in alphabetical asset lists.
  Extension L2 token lists and send selectors are also sorted.
- KRC20/KRC721/KCC20 tickers retain uppercase spelling throughout extension
  asset views. KNS spelling is preserved.
- Extension send preselection handles ticker casing and distinguishes KCC20
  tokens by covenant ID, not just their displayed ticker.
- Extension Lock, Settings and copy/verification controls are 38×38 px;
  network selection is 76×38 px with centered icons and 5 px control gaps.

## Android KNS pagination

- Supports additional pagination response formats and continues past short
  pages when completion has not been established.
- Earlier pages remain visible if a later page fails; incomplete loading is
  explicitly identified. Different asset IDs are not merged only because
  they share a displayed name.
- Page count and time limits remain bounded. This is not a claim that every
  indexer can always return every holding during an outage.

## Downloads and compatibility

- Android: `space.kaspire.wallet`, versionCode **98**, minSdk **30** (Android 11),
  targetSdk **36**, armv7 + arm64. Build 98 supersedes both HUB21 test builds.
- Existing v3/v3.1 Android signing lineage is retained: legacy signer for
  Android 11/12; existing Kaspire release signer for Android 13+.
- Website, signed in-app update manifest and WalletConnect installation
  fallback point to the new Android release. The website serves only its
  latest APK; old website APK links redirect without caching.
- The extension ZIP is the unchanged tested 0.4.7.1 package already submitted
  by the maintainer to Chrome Web Store review. Its manifest version name
  still includes “HUB21 test” to preserve the submitted package exactly.
  **Store review is pending; GitHub publication does not mean Store approval.**

## Checks

- Android analysis clean; 102 Flutter tests pass.
- Extension TypeScript check clean; 33 Node/WASM tests pass.
- Local Chromium fixture checks cover sorting, ticker case, selected assets,
  KNS spelling, theme switching, header geometry, tooltip dismissal and L2.
- Website latest-only APK preparation validates the signed manifest's hash.
- No live transfers were made for these regression tests.

Checksums are supplied in `0.11.30-SHA256SUMS.txt` with this release. The signed Git
tag identifies the source commit; the APK uses the existing Android lineage.
