# Kaspire Android 0.11.41

This Android hotfix completes the native approval flow for GothDAG Covenant
Dragons.

## Covenant Dragons

- Show a human-readable approval review for Covenant Wyrm genesis transactions.
- Show a human-readable approval review for Covenant Wyrm state transitions.
- Bind the displayed serial, element or action, covenant ID, permanent template,
  reserve and network fee to the native Rust preparation result.
- Keep the existing fail-closed origin, owner, serial and element restrictions.

## Security and compatibility

- Preserve the package ID, Android 11+ support and established Android signing
  lineage so existing installations can update normally.
- Keep transaction construction, validation and signing inside the pinned native
  Rust core and Android approval boundary.
- Keep the signed Android update manifest on the pinned Kaspire download host.
